# RTE-UI00 — Desktop completo navegável com Mock JSON

## Pré-condição
Research + Architecture + Task Breakdown concluídos.

## Objetivo
Implementar TODAS as telas fornecidas em `references/screens/`, respeitando fielmente os layouts.

## Obrigatório
- WPF/MVVM;
- shell e navegação completa;
- todas as telas;
- todos os menus;
- estados visuais relevantes;
- dados provenientes de JSON mock;
- fluxo navegável ponta a ponta;
- Configurações com instalação detectada simulada e paths de perfil configuráveis;
- nenhuma dependência de Docker/PostgreSQL/API/n8n.

## Quality Gate
Executar o Desktop e permitir validação visual.

Depois:
STOP.

Não iniciar Domain real, Map Extractor, Graph, Routing, Telemetry ou integrações sem aprovação explícita.
