# Arquitetura do GFM TruckHub

Os desenhos oficiais e editáveis ficam em `drawio/`. Exportações ficam em `exports/`.

O diagrama inicial `GFM-TruckHub-AWS-Target.drawio` descreve a separação entre Desktop Local/Offline, Core e AWS Target. Ele é um baseline arquitetural e deve ser atualizado conforme a implementação real evoluir.
