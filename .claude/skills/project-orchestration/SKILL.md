# Project Orchestration
Use para iniciar, executar ou concluir qualquer task.
1. Leia `PROJECT-STATE.md` e `tasks/CURRENT.md`.
2. Abra a task exata.
3. Liste escopo permitido, proibido, critérios e gates.
4. Carregue apenas regras/skills relevantes.
5. Execute sem avançar para a próxima task.
6. Rode gates.
7. Gere `docs/reports/<TASK-ID>.md`.
8. Atualize estado apenas com fatos.
9. STOP.
